# Mon espace étudiant

Un petit tableau de bord en français pour organiser les devoirs et garder les prochaines échéances en vue. Le projet utilise uniquement **HTML, CSS et JavaScript**.

**[Ouvrir le site](https://7amzvv.github.io/tableau-etudiant/accueil.html)** · [Voir le dépôt](https://github.com/7amzvv/tableau-etudiant)

## Les trois pages

- **[Accueil](https://7amzvv.github.io/tableau-etudiant/accueil.html)** — résumé des tâches restantes et terminées, avec la prochaine échéance.
- **[Mes tâches](https://7amzvv.github.io/tableau-etudiant/taches.html)** — ajouter un devoir, indiquer son cours, sa date et sa priorité, puis le marquer comme terminé.
- **[Planning](https://7amzvv.github.io/tableau-etudiant/planning.html)** — retrouver les tâches datées à venir dans l’ordre chronologique.

La navigation en haut de chaque page permet de passer de l’une à l’autre.

## Utilisation

Le site est publié avec GitHub Pages. Ouvre [l’accueil du site](https://7amzvv.github.io/tableau-etudiant/accueil.html) pour commencer.

Pour le lancer sur ton ordinateur, télécharge ou clone le dépôt, puis ouvre `accueil.html` dans un navigateur. Il n’y a rien à installer.

> L’accueil s’appelle `accueil.html` : le projet contient volontairement trois pages nommées séparément et pas de `index.html`.

## Enregistrer les tâches

Les tâches sont sauvegardées dans le stockage local du navigateur. Elles restent disponibles sur le même appareil et dans le même navigateur. Elles ne sont pas synchronisées entre plusieurs appareils. Effacer les données du navigateur peut aussi effacer les tâches enregistrées.

## Fichiers du projet

```text
accueil.html    Page d’accueil et résumé
taches.html     Ajout et suivi des tâches
planning.html   Échéances à venir
style.css       Mise en forme commune
script.js       Affichage, filtres et sauvegarde
```

## Ce que ce projet m’a permis de pratiquer

- Créer plusieurs pages HTML reliées par une navigation simple.
- Mettre en forme une interface responsive avec CSS.
- Manipuler des formulaires et mettre à jour le contenu avec JavaScript.
- Enregistrer des données dans le navigateur avec `localStorage`.
- Filtrer et trier des tâches selon leur état et leur échéance.
